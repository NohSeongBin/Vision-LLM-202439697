# Python Assignment

## 1. 과제 설명
NumPy를 활용하여 학생들의 성적 데이터를 분석하는 프로그램입니다.

주요 기능:
- 학생 이름 추출
- 성적 데이터 1차원 배열 변환
- 85점 이상 성적 개수 계산
- 학생별 평균 점수 계산
- 최고 평균 점수 학생 확인
- 전체 최고 점수 및 해당 과목과 학생 확인

## 2. 실행 환경
- Python 3
- NumPy

## 3. 참고 사항
- 학생 5명의 3과목 성적 데이터를 사용합니다.
- NumPy를 활용하여 평균 및 최고 점수를 계산합니다.
- 실행 결과는 터미널에 출력됩니다.
